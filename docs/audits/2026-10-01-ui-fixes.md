## Review resolutions

The final ce-code-review examined all17 fixes. Its two reproduced reliability findings were resolved:

- `9ce0e4a`: Connection test responses now check an input version before updating metadata/status/errors. Endpoint, authentication and credential edits invalidate the test state. Delayed success and delayed failure both leave edited inputs untested.
- `556e70d`: Saving a removed source now writes configuration once, excludes deleted source tabs/selection from persistence, and closes the active tab without a second write. A failure injected into the second write no longer turns a successful settings save into an error.
- The existing delayed-save test additionally proves that Save changes keeps Settings open and disables discard while persistence is pending, then closes after success.

The two remaining testing gaps are closed: the first restored request is asserted for both absolute and relative15-minute ranges, and a failed settings save preserves the open tailer, range, rows and its ability to query the old filter.
